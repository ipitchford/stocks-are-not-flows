# Authorship and computational-assistance disclosure

## Public discussion preprint

The v1.0.0 preprint and Zenodo record use the creator label **Anonymous**. The
public Git history is deliberately squashed under an anonymous noreply identity;
the `ipitchford` GitHub account is the repository host, not a scholarly-author
claim.

The supplied project originated in Gary Stevenson's 2019 MPhil thesis, which is
cited as intellectual provenance. That does not make Stevenson an author of this
preprint.

## Computational assistance

Automated research and coding systems assisted literature discovery, source
triage, model and test implementation, adversarial critique, verification, and
manuscript drafting. Automated systems are not authors. An accountable human
author must review and accept responsibility for the paper, sources, code, and
declarations before any journal submission.

No funding, affiliation, ORCID, CRediT-role, or competing-interest information
is asserted in this anonymous public discussion release. Those fields remain a
journal-submission requirement.
